CNCSearch — Melhoria da ingestão de cânticos

Runbook passo a passo para correres no teu PC · Branch claude/chant-ingestion-analysis-2qfryl

Objetivo: reduzir os erros e "caracteres esquisitos" nas letras dos cânticos, melhorando tanto a leitura como a qualidade da pesquisa semântica (as letras alimentam os embeddings). O âmbito acordado são quatro frentes:

#MelhoriaResolve
#1Módulo único de limpeza de texto, aplicado em todos os caminhos de importação e na edição manualRuído: nºs de página, símbolos soltos, anotações de cifra, linhas duplicadas, normalização Unicode (NFC)
#2Script de re-limpeza da base de dados existente + re-indexaçãoLimpa os cânticos já importados sem reprocessar imagens
#3OCR ciente de colunas (dividir a pauta nas colunas antes do OCR)A ordem dos versos baralhada — o problema mais grave, que a limpeza não consegue corrigir
#4Filtragem por confiança do OCR (image_to_data) + marcação de cânticos para revisãoDescarta tokens-lixo e identifica letras de baixa qualidade
Claude eu escrevo/entrego o código (em PRs seguintes) Tu executas no teu PC (precisa de rede, Tesseract e Chromium)
Porque é que estes passos são teus. O ambiente remoto do Claude Code não tem acesso de rede a media.ressuscitou.pt / app.resucito.es (bloqueados pela política de egress), nem tem o Tesseract ou o Chromium instalados. Reprocessar OCR é, por isso, uma operação local. Eu só preciso de ver 1–2 imagens de exemplo para calibrar a divisão de colunas do #3.

Fase 0 Preparar o ambiente local Tu

Comandos em PowerShell (Windows), a partir da raiz do repositório (ex. C:\DEV\CNCSearch). Em Linux/macOS os comandos python/pip são equivalentes.

# 1. Obter o branch de trabalho
git fetch origin
git checkout claude/chant-ingestion-analysis-2qfryl
git pull origin claude/chant-ingestion-analysis-2qfryl

# 2. Ambiente virtual + dependências do projeto
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# 3. Browser do Playwright (necessário para obter a lista de cânticos)
playwright install chromium

Instalar o Tesseract OCR + pacote de Português

# Windows (via winget)
winget install UB-Mannheim.TesseractOCR

# Confirma que o idioma 'por' está instalado:
tesseract --list-langs        # deve aparecer "por" na lista
tesseract --version

Se o por não aparecer, no instalador UB-Mannheim escolhe Additional language data → Portuguese, ou copia por.traineddata para a pasta tessdata. O script já aponta para C:\Program Files\Tesseract-OCR\tesseract.exe no Windows.

Backup obrigatório antes de mexer na base de dados. As Fases 2 e 3 alteram data/cncsearch.db. 
# Copia de segurança datada da BD
Copy-Item data\cncsearch.db ("data\cncsearch.backup-{0}.db" -f (Get-Date -Format "yyyyMMdd-HHmmss"))
  • Branch claude/chant-ingestion-analysis-2qfryl obtido
  • pip install -r requirements.txt sem erros
  • playwright install chromium concluído
  • tesseract --list-langs mostra por
  • Backup de data/cncsearch.db criado

Fase 2 Limpeza de texto + re-limpeza da BD (#1, #2) Claude → Tu

Claude entrega: um módulo de limpeza partilhado (ex. cncsearch/ingest/clean.py) ligado a todos os caminhos de importação e à edição manual, mais um script scripts/reclean_db.py para sanear as letras já existentes.

Tu executas:

# Obter o código novo
git pull origin claude/chant-ingestion-analysis-2qfryl

# 1. Pré-visualizar a limpeza SEM gravar (mostra um diff por cântico)
python scripts/reclean_db.py --dry-run

# 2. Se o diff fizer sentido, aplicar à base de dados
python scripts/reclean_db.py --apply

# 3. Re-indexar embeddings (as letras mudaram → os embeddings têm de ser refeitos)

Re-indexação faz-se na Web UI: Definições → "Re-indexar todos os cânticos". (É o endpoint POST /reindex; gera novos embeddings via Jina ou modelo local.)

  • reclean_db.py --dry-run revisto e aprovado
  • reclean_db.py --apply executado
  • Re-indexação concluída na Web UI (Definições mostra 0 cânticos sem embedding)

Fase 3 Re-OCR por colunas + confiança (#3, #4) Claude → Tu

Claude entrega: resucito_import.py revisto — divide a imagem nas colunas antes do OCR, lê cada coluna de cima a baixo, e usa image_to_data para descartar tokens de baixa confiança e marcar cânticos duvidosos para revisão.

Tu executas:

# Obter o código novo
git pull origin claude/chant-ingestion-analysis-2qfryl

# 1. Teste em poucos cânticos, SEM escrever na BD — inspeciona a ordem dos versos
python scripts/resucito_import.py --dry-run --limit 5

# 2. Quando a ordem/qualidade estiverem bem, correr a importação completa
#    (o script salta duplicados; para REPROCESSAR letras já existentes
#     segue a indicação do PR — provavelmente uma flag --reocr)
python scripts/resucito_import.py

# 3. Re-indexar novamente na Web UI (Definições → Re-indexar)
Atenção ao reprocessamento. O importador atual salta cânticos cujo título já existe. Para substituir letras antigas pelas novas (OCR melhorado), o PR incluirá a forma correta de o fazer (flag dedicada ou limpeza prévia). Faz sempre o --dry-run primeiro e confirma o backup da Fase 0.
  • --dry-run --limit 5: ordem dos versos correta nas colunas
  • Importação/reprocessamento completo executado
  • Re-indexação concluída

Fase 4 Verificação final Tu

  • Abre a Web UI e revê 5–10 cânticos que antes estavam piores (ex. A Espada, A Ti levanto os meus olhos).
  • Confirma que desapareceram: números de página soltos, símbolos isolados, anotações de cifra (Travessão / trasto), e versos baralhados entre colunas.
  • Faz 2–3 pesquisas de teste (ou via /canticos no Telegram) e confirma que os resultados melhoraram ou se mantiveram coerentes.
  • Revê a lista de cânticos marcados "para revisão" (#4) e corrige manualmente os que ficarem.
  • Amostra de cânticos verificada na Web UI
  • Pesquisas de teste OK
  • Cânticos sinalizados para revisão tratados
