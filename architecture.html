CNCSearch

Purpose: Semantic search engine for Portuguese liturgical canticles. Provides a web UI (Bootstrap 5), a Telegram /canticos command, uses Jina AI or local embeddings, SQLite for persistence, and includes rate limiting.
PythonFastAPIBootstrap 5Jina AI EmbeddingsSQLiteTelegram BotDocker

Architecture Overview

Key Workflows

Semantic Search
User enters text query in web UI or sends /canticos via Telegram → query embedded with Jina AI (or local model) → cosine similarity search against stored canticle vectors in SQLite → top matches returned with title, lyrics excerpt, and confidence score.
Canticle Ingestion
CSV of canticles loaded → each canticle text embedded → vectors stored in SQLite alongside metadata → BM25 index optionally built for hybrid search.
Rate Limiting
Per-IP rate limiting prevents API abuse → configurable limits per endpoint → Telegram bot has per-user cooldown.
