1. What this project does

Purpose

Upload and manage a parish hymn database. Given any biblical passage or liturgical text, find the most thematically similar hymns using cosine similarity on sentence embeddings. Accessible via a secured web interface and Telegram bot commands.

6. Docker setup

cncsearch

FastAPI app on :8080. Shared cncsearch_data volume for SQLite accessible across containers.

cncsearch_caddy

HTTPS proxy

Caddy 2 with sslip.io automatic TLS. Routes external HTTPS traffic to cncsearch:8080.

Telegram bot

GarminBot extended with CNCSearch handlers via PYTHONPATH mount. Shares cncsearch_data volume.
